## 自动化测试分层

| 命令 | 用途 | 是否访问外部服务 |
| --- | --- | --- |
| `pnpm test:unit` | 核心纯函数、面试控制策略、路由选择和 API 边界 | 否 |
| `pnpm test:ai` | 真实模型追问止损、原话锚定和 Coach 引用评测 | 是，显式执行才产生费用 |
| `pnpm test:ai:report` | 同上，并生成 `evals/results/latest.json` 机器可读报告 | 是 |
| `pnpm test:all` | 单元测试、类型检查、生产构建 | 否 |

GitHub Actions 默认执行 `pnpm test:all`。AI Eval 不在每次 push 时自动调用，避免密钥暴露、模型费用失控和非确定性结果阻塞部署；发布前由维护者在受控环境显式执行并保存报告。
