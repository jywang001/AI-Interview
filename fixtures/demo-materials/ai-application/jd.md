# 云帆科技｜AI 应用开发工程师（校招）｜虚构 JD

> 本岗位和公司均为虚构，仅用于 AI Interview 产品演示。

## 岗位职责

1. 将大模型、RAG 或 Agent 能力集成到 Web 产品和后端服务中，交付可验证的用户流程。
2. 设计清晰的 API、数据流和状态模型，处理超时、重试、幂等、降级和错误恢复。
3. 建设离线评估与线上监控，持续分析效果、延迟、成本和失败样本。
4. 与产品和算法团队协作，把不稳定的模型输出约束成可维护的工程接口。

## 必备能力

- 熟练使用 TypeScript 或 Python，能够独立完成 Web API 与服务端业务开发。
- 理解 HTTP、数据库、缓存、异步任务和常见服务可靠性模式。
- 有 LLM API、RAG、结构化生成或 AI 工作流项目经验。
- 能说明项目中的个人决策、技术权衡、量化结果和已知限制。

## 加分项

- 有 Next.js、Node.js、FastAPI、Docker 或云端部署经验。
- 做过 RAG/Agent 评估、Prompt Injection 防护或模型降级。
- 具备基本的监控、日志、成本控制和容量规划意识。

## 面试重点

- 能否完整解释一次请求从浏览器到模型再到返回结果的数据流。
- 如何判断 RAG 或 Agent 版本真的变好，而不是只优化了演示案例。
- 模型超时、限流或不可用时如何保证核心流程可继续。
- 当流量扩大十倍、推理预算减半时如何排序优化方案并设置质量护栏。
